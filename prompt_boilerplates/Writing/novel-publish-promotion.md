# 小说平台发表与推广（不含社交媒体与视频）

## 任务目标

为网络小说与文学连载提供可复用的平台发表与推广流程。**两条线分明**：

- **引流策略**：作品被看见、被点击的「商品面」——书名、笔名、简介文案、封面、标签、开局钩子。核心问题：读者凭什么点进来。
- **发表策略**：平台规则操作——平台选择、分类、更新频率、发布时间、入V/付费结构、定价、独家协议、平台内运营。核心问题：在哪个平台、怎么发、怎么经营。

含英语平台（Wattpad/WebNovel 等）宣传策略。**边界铁律**：不含社交媒体宣传与视频手段——微博、小红书、抖音、B站、微信视频号、LOFTER 等外部渠道，及视频制作、配音、直播、短视频推广，一律排除。

## 执行流程

### 0. 两条线关系（先行理解）

- **先后**：先定发表策略（平台决定文案格式、标签体系、节奏约束），再按平台定制引流策略。
- **咬合**：Tag 兼具引流与发表属性——引流篇讲吸引力（曝光/筛选），发表篇讲权重规则（前 4 位决定榜单曝光）。
- **输出**：方案文档分「引流策略」与「发表策略」两编呈现，勿混为一谈。

### 1. 作品定位与平台匹配评估（发表策略·前置）

动笔之先，读项目档案（GOAL、风格档案、题材、篇幅、进度），再依维度评估候选平台：

| 维度 | 考察内容 |
|-----|---------|
| 题材适配度 | 耽美/文学/爽文与平台主流品类契合否 |
| 读者画像 | 付费意愿、评论质量、阅读耐心、年龄结构 |
| 付费模式 | 订阅/广告分成/打赏/会员/阅读时长分成 |
| 签约难度 | 门槛、周期、独家限制 |
| IP 出口 | 广播剧/出版/漫画/影视改编路径 |
| 审查尺度 | 敏感设定存活率 |

中文平台知识速查（2026 年中基准，动态以官方为准）：

| 平台 | 核心模式 | 适配 | 备注 |
|-----|---------|-----|-----|
| 晋江文学城 | 付费订阅（千字 3 分）+ 版权代理 | 耽美/女频 ★★★★★ | 版权归作者，IP 出口最全 |
| 长佩文学 | 付费 + 打赏（玉佩） | 纯耽美 ★★★★ | 流量约为晋江 1/10-1/20，非签约可提现 |
| 豆瓣阅读 | 付费连载（豆券）+ 会员 + 编辑邀请制 | 社会派/文学性 ★★★★★ | 出版转化率中文平台最高 |
| 番茄小说 | 免费 + 广告分成 | 泛娱乐 ★★（耽美非主流） | 慢热不适配，短剧路线耽美不通 |
| 起点中文网 | 付费订阅 | 男频为主 ★（耽美无生存空间） | 不推荐 |

### 2. 平台选择决策（发表策略）

- **首发平台**：依题材基因选定——耽美强强/末世 → 晋江纯爱频道；社会派/文学性 → 豆瓣阅读社会现实分类；英文向 YA/BL → Wattpad 或 WebNovel（见步骤 7）。理由须写清（题材红利、对标可见度、IP 孵化起点），风险亦须正视（签约周期、竞争强度、审查）。
- **辅助平台**：长佩可与晋江同步（用户重叠约 20%，两边作话风格区分）；WebNovel 于晋江连载 30-40 章后启动翻译（中文领先 20 章）。
- **独家限制**：晋江签约后禁在其它网站发布；豆瓣阅读编辑对全网同步作者降权——**首发独家**。
- **不推荐平台**：逐一举证（如番茄耽美非主流、慢热不兼容；起点男频主导）。
- **完结后引流**：完结半年后可将全文免费发布至番茄获长尾广告（先确认无独家协议）。

### 3. 引流策略：书名、笔名、简介、封面、标签

本步骤产出「作品商品面」——读者未读一字前所见的全部。

#### 3.1 书名策略

| 类型 | 范式 | 示例 |
|-----|-----|-----|
| 中文网文向 | 高概念 + 反差 + 意象 | 《他在永夜种花》（动作+地点+意象，书名与设定反转咬合） |
| 中文古风向 | 四字 + 双关意象 | 《花蚀暗渡》（花蚀/暗渡双层含义） |
| 中文文学向 | 克制 + 隐喻空间 | 《滤镜之下》（美颜滤镜/看待世界之方式双关） |
| 英文向 | 本地化不直译 | The Gardener of Eternal Night 优于 He Plants Flowers in Eternal Night |

- 检验标准：一句话能被复述；有记忆点；不与同类撞名；与简介钩子呼应。
- 书名即第一引流物——改名前用 `ask_user` 确认，禁自行定名。

#### 3.2 笔名策略

- 全网统一笔名（如 quasi-pro），跨书积累品牌资产。
- 英文平台可视品牌策略另设英文笔名；中文平台笔名一致性优先。

#### 3.3 简介文案

- **晋江黄金结构** = 核心 Hook（加粗置顶）+ 世界观速写（一段）+ 人设亮点（双人对称）+ 阅读承诺（Tag + 甜虐比 + HE）。
- **豆瓣格式** = 一句话简介（≤15 字）+ 作品简介（150-200 字）+ 排雷提示。
- **英文 blurb 格式** = Hook（1-2 句高张力）+ Stakes（代价/赌注）+ 悬念收尾；禁剧透简介。
- 文案五技巧：第一句必有画面；反转期待钩子（书名暗示与读者预期相反）；具体数字增可信度（「两年后」「一千万」「第 101 年」）；对标暗示靠风格不直写；残酷设定暗示不点破（「两年后人变成花」是诗意，「两年后你会死」是恐怖片宣发）。
- 排雷提示（文学向）：明写非爽文/非甜文/结局不和解，过滤错配读者，提升留存与口碑。

#### 3.4 封面

- 文学向/豆瓣：简洁、有设计感；禁花哨堆砌。
- 晋江：竖版书封，书名大字，风格与题材一致。
- Wattpad 等英文平台：**移动端缩略图可读**——文字大、对比强、小图仍可辨。
- 项目已有封面题图方案（如 `封面题图方案.md`）则直接继承，勿重做。

#### 3.5 标签/关键词（引流视角）

- 标签双功能：**曝光**（进推荐流/榜单）+ **筛选**（精准吸引目标读者、过滤错配）。
- 晋江前 4 个 Tag 决定搜索曝光权重（权重规则见发表策略 4.1）。
- 豆瓣关键词 8-10 个，覆盖题材、结构、人群（如：底层叙事、双线结构、都市情感、社会派、中老年、孤独）。
- 英文平台 Tag 数量上限与排序规则见步骤 7。

### 4. 发表策略：平台参数配置

#### 4.1 分类、Tag 权重与关键词（发表视角）

**晋江**：前 4 个 Tag 决定搜索曝光权重，排列非随意：

```text
1. 强强（最大流量池）→ 2. 末世（题材稀缺）→ 3. 穿越时空（流量交叉）→ 4. 情有独钟（洁癖筛选器）→ 5. 种田文（差异化）→ 6-8. 人设/HE/风格
```

避坑：禁「虐恋情深」（与强强双向救赎定位矛盾）；「慢热」慎用（劝退快节奏读者）——节奏暗示放文案，勿用 Tag。

**豆瓣阅读**：一级分类：小说 > 社会现实。

#### 4.2 更新频率与发布时间

| 阶段（晋江） | 频率 | 字数/章 |
|:----|:----|:----|
| 签约前（Ch.1-15） | 日更 | 3000-3500 |
| 入 V 前（Ch.16-25） | 日更 | 3500-4000 |
| 入 V 后（Ch.26-60） | 日更或隔日更 | 4000-4500 |
| 收尾期（Ch.61-90） | 日更 | 3500-4000 |

- 晋江固定 22:00 发布：避开 21:00-21:30 大神潮，读者追更完毕刷「最新更新」空窗期恰逢其时；留 4-5 小时上榜窗口。
- 每周固定一日加更（2000-2500 字番外）而非休息；请假提前 3 章作话预告，禁突然断更。
- 豆瓣阅读周更 2-3 次，晚间 20:00-21:30（流量高峰）；前 3 章周更 2 次，留编辑发现时间。

#### 4.3 免费/付费结构与入 V（晋江）

- 推荐：第 25 章入 V，倒 V 至第 15 章（免费 14 章 + 倒 V 10 章）。
- 入 V 时机选情感升温点（首钩子后、感情实质升温处），勿过早过晚。
- 入 V 操作清单：提前一周作话预告 → 前夜免费章卡钩子 → 当日发两章 → 首周不断更（首周数据决定编辑推荐位）。
- 定价：千字 4 晋江币（中等偏上）。

#### 4.4 定价（豆瓣阅读）

Ch1-3 免费（双线结构须 3 章建立模式）→ Ch4-5 定价 2 豆券（降首次付费门槛）→ Ch6-9 定价 3 豆券（核心内容正常价）→ 结局章降价或免费收尾。

### 5. 开局策略（引流策略·执行期）

- 前三章各完成一事：Ch1 一个画面 + 一个问题；Ch2 一个规则 + 一个恐惧；Ch3 一个选择 + 一种温度（冷面角色首现温度细节，如「口袋里捂热的压缩饼干」）。
- 前 3 天节奏：第 1 天发首章观察自然流量；第 2 天发二章并回评；第 3 天发三章，作话正式亮相。
- 豆瓣前 3 万字定编辑注意：留存率、评论质量、收藏/推荐比三信号。
- **付费触点**（文学向）：章末情感未完成感钩子四类——画面定格 / 未说完的话 / 日常中的异常 / 对称钩子；禁人为悬念（「突然，门开了」）。
- 防流失节点：首次付费章（Ch3→4）风险最高，Ch3 结尾强情感钩子 + Ch4 开头分量足；大高潮后回落（见面后）须先埋另一线钩子。

### 6. 平台内运营（发表策略·持续期）

#### 6.1 评论区

- 三七法则：30% 正经回复 + 70% 轻松互动。
- 前 10 条评论必回；玩梗式回复优于感谢式（埋后续剧情梗、角色口吻吐槽）。
- 把设定变读者「内部梗」，制造圈层归属。
- 负面评论三分类：剧情讨论 → 认真回复不辩解；恶意攻击 → 不回不删不置顶；举报风险 → 温和转移焦点（声明无现实映射）。
- 高质量长评加精置前——长评即免费安利文案。

#### 6.2 晋江作话

- 五功能定位：轻松卖萌（每章）/ 预告钩子（每 3-5 章）/ 创作幕后（每周 1-2 次）/ 读者互动（每周 1-2 次）/ 数据里程碑（达成时）。
- 风格：口语化情绪词、自我吐槽、角色「人间真实」buff、适度剧透不完整透。
- 禁忌：不抱怨数据、不调解吵架、不透隐私、超 200 字即冗。

#### 6.3 豆瓣创作手记与编辑争取

- 每章结尾附创作手记（≤50 字）：真实生活观察或创作动机，非「求收藏」话术。
- 两次更新后主动投稿专题（编辑推荐 / 新作速递 / 社会现实），作者后台可申请。

#### 6.4 种子读者

发表前聚 5-10 个种子读者提前阅读反馈：平台相关小组活跃成员、领域意见领袖、创作社群群友。

### 7. 英语平台宣传策略

中文平台之外的第二市场。英语平台以**免费吸粉 + 社区驱动 + 影视改编可能**为主，付费能力弱于晋江，定位为增量市场与 IP 跳板。

#### 7.1 Wattpad（社区驱动型）

**平台特征**：
- 全球最大网文社区之一；免费阅读为主（广告）+ Paid Stories（付费故事计划）
- 读者以 Gen Z / 千禧一代女性为主；社区文化强——段评（inline comments）、阅读清单（reading lists）、书友圈
- 算法推荐为主，新作品有初始曝光窗口；完本作品（completed）在搜索/推荐更受偏爱

**引流策略**：
- 书名与 blurb 须本地化（见 3.1/3.3），禁直译中文表达
- Tag 有数量上限（约 25 个，常用 5-10 个），前几个 Tag 决定推荐流——按题材选：romance、lgbtq+、boyslove、dystopian、slowburn 等
- 封面按移动端缩略图设计：文字大、对比强

**发表策略**：
- 更新稳定（周更 2-3 次或日更），新书期保持高活跃以吃满初始曝光窗口
- 完本优势：尽早标记 completed；完本后可考虑申请 Paid Stories（资格与分成规则动态，以官方为准；通常要求作品不在其它平台免费发布）
- 社区参与：报名 Wattys 年度奖项（入围/获奖即推荐曝光）、加入写作社区与读书会
- 段评运营：在关键段落埋互动点（提问/钩子），读者段评增多会推高互动权重
- 阅读清单：鼓励读者把作品加入书单——书单即推荐位
- 每评必回（与中文平台同理），回复率影响互动权重

**变现与 IP**：Paid Stories（按阅读时长分成）+ Wattpad Studios 影视改编（概率低但存在，改编权谈判时保留其它权利）。

#### 7.2 WebNovel（付费/BL 向）

- 起点国际；付费章节 + 广告；BL 英文市场成熟，翻译作品多
- 与 Wattpad 对比：付费模式收入更高但流量池小；BL 读者精准；**常要求独家英文版权**
- 路径：晋江连载 30-40 章后启动专业翻译（中文领先 20 章），$0.03-0.05/字 预算
- 禁机翻——读者对翻译质量极敏感

#### 7.3 Tapas / Radish（可选补充）

- Tapas：付费章节（虚拟货币）+ 漫画共生生态；适合快节奏、短章作品
- Radish：剧集式付费（episode-based）；适合强悬念、钩子密集的短篇
- 两者的推荐权重、付费门槛动态变化，入局前以官方为准

#### 7.4 英语平台选择逻辑

| 作品特征 | 首选 | 次选 |
|-----|-----|-----|
| BL / 已有中文热度 | WebNovel（独家英文） | Wattpad |
| YA / Romance / 社区互动型 | Wattpad | Tapas |
| 短篇 / 强悬念 / 剧集式 | Radish | Tapas |
| 完本后多平台免费引流 | Wattpad + 自建 | — |

- 多平台并行注意独家条款（WebNovel 独家英文 vs Wattpad 非独家）。
- 英语平台与中文平台无冲突，可同步运营（内容语言不同，不违反中文独家协议）。

### 8. 收入模型与长线变现

- 收入模型：订阅（晋江千字 3 分，作者分成 50-60% 起；豆瓣豆券约 50%）+ 全勤奖（晋江按 VIP 收入 7%-18% 阶梯）+ 打赏 + 版权收入 + 英文平台（Paid Stories 阅读时长分成 / 广告分成）。
- IP 路径：广播剧（猫耳FM，行情 3-30 万，连载至 Ch.50 口碑稳定后接触版权编辑）→ 漫画（先做视觉短篇试水，勿直接全篇改编）→ 实体出版（豆瓣系投稿理想国/后浪/新经典/上海文艺/单读）→ 海外（WebNovel/Amazon KDP/东南亚，英文优先）→ 影视（Wattpad Studios 等，概率最低金额最大）。
- **版权切割铁律**：按语种/地区/媒介分开授权，禁签「全球版权」一揽子协议。
- 收入预测分保守/中性/乐观三档，写明前提（均订数），勿夸大。

### 9. 输出推广方案文档

按下列结构输出《书名_发表渠道策略.md》（引流与发表两编分明）：

```text
第一编·引流策略
├── 书名/笔名（方案 + 检验 + 备选）
├── 简介文案（中文结构 + 英文 blurb + 排雷）
├── 封面（规格 + 风格方向）
└── 标签（曝光/筛选双功能 + 排序）
第二编·发表策略
├── 平台选择（首发/辅助/不推荐 + 理由）
├── 平台参数（分类/Tag 权重/更新频率/发布时间/入V/定价）
├── 开局与平台内运营（前三章/评论区/作话/创作手记/编辑争取）
└── 英语平台（Wattpad/WebNovel/Tapas/Radish 选择与打法）
第三编·长线
├── 收入模型与预测（保守/中性/乐观）
├── IP 与出版路径（版权切割）
└── 综合发表路线图（按月分段）
```

另输出《书名_发表信息表.md》（平台注册/发表用）：立意、关键字、体量、内容标签、角色卡、分类、关键词。

按 `mode` 可输出单项：`config`（仅发表参数表）、`copy`（仅文案与书名）、`ops`（仅平台内运营计划）。

### 10. 数字核查（可选但推荐）

方案含大量具体数字（分成比例、收入估算、平台规则、Tag 上限）时，遵循数字信息事实核查原则：用 `web_search` 检索平台官方最新规则，或委托批判性子代理（`momus`/`oracle`）核查幻觉与来源可信度；输出标注可信度等级（高/中/低）及核查差异。subagent 调用须带 `timeoutMs`。

## 输出格式

输出两份文档（`write` 新建，已存在则 `edit` 更新）：

1. **《书名_发表渠道策略.md》**：按步骤 9 结构，引流/发表两编分明，含表格与操作清单，附综合发表路线图。
2. **《书名_发表信息表.md》**（平台注册/发表用）：立意、关键字、体量、内容标签、角色卡、分类、关键词。

## 注意事项

- **引流 ≠ 发表**：书名/简介/封面/标签吸引力属引流；平台规则操作（更新节奏/入V/定价/独家协议）属发表。方案文档两编分明，禁混写。
- **社交媒体与视频手段禁入**：低级黑高级红、恶意批判式推广、B站/抖音吐槽视频、文生视频、配音字幕、多平台一键分发脚本、外部社交媒体账号运营——皆不在本 skill 范围；用户若要求，明确提示属另一渠道体系，勿混入。
- **平台规则动态变化**：文中数字（分成比例、全勤、豆券定价、Tag 权重与上限、Paid Stories 资格）为 2026 年中基准，执行前须以平台官方最新规则核对。
- **英文本地化非机翻**：书名、blurb、Tag 须按英语读者习惯重写；WebNovel 需专业翻译预算（$0.03-0.05/字）。
- **独家与版权**：晋江签约独家后禁多平台发布；豆瓣阅读编辑对全网同步降权；WebNovel 独家英文 vs Wattpad 非独家须先定；海外授权按语种/地区切割，禁一揽子协议。
- **审查风险**：敏感设定（人体转化/制度批判）用暗示与留白处理，防举报；文案不直写残酷明面。
- **收入预期管理**：新书连载收入多为千元级，IP 才是天花板——写作兼顾「IP 改编友好」（场景感强、对白精炼、情感爆发点清晰）。
- **数据口径**：评论互动、留存率等信号以平台作者后台为准，禁臆造。
- **分工边界**：创作全流程见 `web-novel-writing`；本 skill 只管发表与推广，两者互补不重叠。
- **用户确认**：平台选择、入 V 节点、定价、书名等关键决策若存歧义，先 `ask_user` 再定，禁代用户决定。
