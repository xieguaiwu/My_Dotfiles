# 网络小说写作通用流程

## 任务目标

为网络小说（耽美/百合/言情/一般向皆可）提供从创意到成稿的可移植创作流程：创意引擎、人物档案、全篇爆点布局、分章施工手册、逐章写作、结构审查与一致性核验。**语言风格不作预设**——由用户选定，skill 禁自行确认。不涉推广运营内容。

## 执行流程

### 0. 语言风格确认（先行步骤，禁自行决定）

语言风格为本 skill 唯一不预设之参数。动笔前必先定风格档案，否则禁进入写作。

- **来源三选一**：
  - 用户已供风格样本/写作风格指南/对标作品 → `read` 之，提炼风格画像
  - 用户未供 → 用 `ask_user` 询问，示结构化选项（见下），收用户选择后方可继续
  - 项目已有施工文档/风格档案 → 直接继承，不重复询问
- **风格画像维度**（记入 `风格档案.md`，存项目根目录）：

| 维度 | 选项 | 说明 |
|:-----|:-----|:-----|
| 句式基准 | 短句为主 / 长短交替 / 长句铺陈 | 句长基准、段落长度、一句一事实或一句多意 |
| 破折号策略 | 禁用 / 限量（如每章 ≤25）/ 不限 | 极简风格零破折号；华丽风格可保留 |
| AI 痕迹规则 | 严格 / 宽松 | 执行强度与破折号额度见步骤 8。严格：禁「仿佛/好像/似乎」「某种/一丝/一抹」「那一刻/那一瞬间」「突然/忽然/猛地」「却/竟/便」「是……的」判断句、连续定语堆砌、「一个声音说」「空气凝固了」等 |
| 描写范式 | 三岛式 / 卡佛式 / 网文爽感式 / 其他 | 三岛式=美在崩溃前的精确；卡佛式=人在沉默中的重量（详见步骤 5） |
| 对话风格 | 极克制（台词上限）/ 自然松弛 | 克制度、留白强度、是否禁心理说明 |
| 情绪密度 | 爽点驱动 / 情绪驱动 | 网文向 3-5 章一小高潮；文学向场景积累渐强式 |

- 风格档案既定，后续每章写作与检查皆依此执行，**禁混用他风格**（如：极简项目不得突然出现华丽比喻；华丽项目不得突然全句号断句）。

### 1. 创意引擎与项目定位

- **创意公式**：经典文学情感原型 × 高概念题材 × 商业结构。
  - 例：末世设定 × 穿越少年反差 × 网文爽感结构；美颜滤镜隐喻 × 双线结构 × 底层叙事。
- **灵感原子提取**：从经典文本提取「情感原子」（如坚韧、偏执、美学堕落、绝境觉醒），重组为新角色，不直接复制人物。
- **一句话简介**：浓缩核心卖点（主角处境 + 冲突 + 关系悬念），须能直接用作宣传语。
- **差异化对照表**：与灵感来源逐项对照创新点（设定/主角/基调/主线/机制），防抄袭、显新意。
- **世界观机制**：核心设定规则明确——代价、边界、不可逆性（例：转花两年不可逆、消耗生命）。机制须为叙事服务：阶级分层即身体描写资源，规则即悬念来源。
- **篇幅与节奏**：由用户定。爽点驱动：3-5 章一小高潮；情绪驱动：场景积累、渐强式。

### 2. 人物设定与档案

每个主要角色建立六张档案，全部入 `角色设定.md`：

**① 角色卡**：表层性格 / 秘密 / 不为人知的一面 / 角色弧线 / 可提取的经典元素。

**② 身体特征档案**（表格）：部位 / 固定特征 / 变化状态 / 优先出现章节。部位覆盖：眼睛、眉毛、嘴唇、牙齿、手、皮肤、脖颈、肩线、腰、膝盖、头发、疤痕等。**固定特征禁临场发挥**——同一颗痣、同一条疤、同一道裂痕须跨章一致。

**③ 行为模式档案**（表格）：行为 / 频率 / 触发条件 / 备注。写「不自知的习惯动作」（数钱蘸唾沫、摸手机裂痕、按膝盖再起身）——身体记得比脑子清楚。

**④ 语言特征档案**（表格）：句式 / 语气词 / 对不同对象的说话方式 / 不说的话。每人设「不说的句子」清单（如「我累了」「帮帮我」不在其字典里），禁越界。

**⑤ 核心物件系统**（表格）：物件 / 来源 / 使用方式 / 叙事功能 / 关键场景。三规则：
- 物件状态=人物状态（屏裂半年不修=对自己「不影响使用就行」）
- 物件动作替人物说话（把手机扣在桌上=觉得自己不该再看）
- 物件变化标记时间流逝（补光灯从床头夹着→拆下装进包里）

**⑥ 空间容器**（表格）：空间特征 / 对应情绪 / 写法指导。写声音、光、气味、门（隔断墙不隔音=无法逃避的他人存在；旧门轻轻合上=用惯了的沉默）。

另建**人物一致性档案**：外貌速查 + 行为模式 + 语言特征 + **核心道具逐章状态跟踪表**（每章列道具状态，写作时逐项核对）。

**感官词库**：每角色一张，分「日常世界」与「亲密场景」两栏，覆盖视觉/听觉/触觉/嗅觉/味觉。用词禁跨世界混用。

### 3. 全篇结构与爆点布局

- **情感主线**：一段话写尽（从 X 到 Y，在 Z 中互相拯救/互相错位）。
- **分卷结构**：卷 / 章节范围 / 功能 / 情绪基调。每卷有明确功能词（坠落与相遇、破冰、秘密花园、危机高潮）。
- **尖叫场景**（全篇 5-7 个）：高记忆点场景，各建档案——前置积累 / 场景结构（建议 3-4 章） / 描写要求 / 台词控制 / 后续影响。**前置积累原则**：爆发前 5-15 章铺垫，让读者「知道但不点破」。
- **威胁升级路线**：Level 1-6（信息预警→制度施压→法律威胁→生命威胁→全面围剿→绝境）。每 10-15 章升级一次；**两次威胁之间必插情感修复期**——以亲密场景升级作缓冲。
- **悬念引爆时间线**（表格）：伏笔 / 埋设章 / 引爆章 / 引爆方式 / 类型。类型分：身份悬念、情感回响、能力悬念、威胁悬念、世界观悬念。伏笔必录表，防漏爆。
- **角色反差路线**：攻「裂缝」披露 1/5→5/5（无意暴露→被告知→主动暴露→无意识暴露→完全暴露）；受「刚硬」成长路线（言语底线→行动刚硬→主动保护）。两者交叉推进。
- **污点→武器反转表**：主角污点（护食/记仇/虚荣/想逃）非缺陷，皆伏笔——于关键节点反转为武器（「舍不得分饼干」→「舍得流血」）。
- **情感升级关键节点表**：卷 / 章节 / 情感事件 / 亲密等级 / 意义。全书亲密度有刻度，可查可核。
- **章节命名表**（可选）：章 / 标题 / 出处 / 作用 / 视角。命名逻辑：物件即情绪、时间即标记、台词即刀刃、日常即结局。

### 4. 亲密递进体系（感情线作品必用）

- **五级递进**，禁跳级：

| 等级 | 含义 | 示例 |
|:----|:-----|:-----|
| ★☆☆ | 视线/空间占有 | 影子笼罩、目光停留、并排站 |
| ★★☆ | 环境层亲密 | 调高温度、留外套、靠近不说话 |
| ★★★ | 非必要触碰 | 检查手指、领口、手腕 |
| ★★★★ | 沉默的亲密 | 不松开的手、不推开的拥抱 |
| ★★★★★ | 公开的秘密 | 拽衣摆、脉搏交叠、电梯手背相碰 |

- **进阶时间线**：逐章标注物理接触刻度——零接触→视线相遇→偶然接触→有意识极限距离（指尖 5cm 悬空）→第一次主动触碰→第一次不受控亲密→公开确认。每个「第一次」都有章位。
- **台词克制规则**：攻方台词按阶段设上限（例：前 15 章 ≤3 句/章、每句 ≤20 字、只陈述事实不表达情绪；中期 ≤5 句；高潮 ≤7 句）。少即是多，沉默比告白有力。
- **变相告白公式**：用行动与责任语言代替直白——用「管」代替「要」，用「责任」代替「爱」（「你的命归我管」=「你是我的」）。
- **亲吻时机管理**：不在情感强度最高处接吻（悲伤场景接吻会消解纯粹性）；首次接吻单设章位；灵魂级场景（认亲/牺牲/精神融合）需比亲吻更深的东西，勿以吻收束。

### 5. 身体描写技法（风格无关骨架）

**三条通用铁则**：
1. **双重负载**：身体细节同时携带阶级/职业信息与情感信息（皮肤=阶级名片；指甲缝机油=三十四年；薄茧=身世）。
2. **档案驱动**：按身体特征档案写，固定特征跨章呼应，禁临场发明。
3. **暴露情境必写部位**：被控制/被检查/昏迷/衣服滑落时，必写脖颈后仰弧线、颈动脉搏动、锁骨、脊柱凸起——慢镜头，衣料离开皮肤的过程。

**手部铁则**：手是情绪的 X 光片——写手在做什么，不写人在感受什么。失控细节：泛白、颤抖、悬停、攥紧、摸裂痕。两双手对比（温度/粗糙度/颜色/姿势）。

**每章底线**：至少 1 处身体部位特写；至少 2 个描写维度（皮肤/嘴唇/眼睛/手）；至少 1 处气味/温度/触感感官描写；至少 1 处两人距离的空间描写（近了/远了/没变）。

**范式二选一（依风格档案）**：

| 三岛式（美在崩溃前的精确） | 卡佛式（人在沉默中的重量） |
|:-----|:-----|
| 光反应皮肤（皮肤+光+交互物质=质感） | 皮肤是材质簿（油/灰/茧/泡皱，禁「粗糙」抽象词） |
| 假想皮肤（触碰后触感残留） | 温度即情绪（冷汗/燥热直接对应心理） |
| 汗的力量化（部位+质地+气味，禁「满头大汗」） | 身体暴露阶级（手/指甲/脖颈自报身份） |
| 眼睛材质化（瞳孔如玄玉/余烬/深井，禁「黑眼睛」） | 光线揭露真相（不同光源揭开不同层次的脸） |
| 回眸的刹那化（不完全、断面、侧影） | 比喻锚定实物（禁「像某种说不清的」） |
| 手为独立叙事体（写手想要什么，不写手在做什么） | 身体有记忆（旧伤疤/冻疮痕不遗忘） |
| 雕塑式身体目录（部件独立发光，不急缝合为完整的人） | 身体羞耻感（不知道往哪儿放的手） |
| 存在感之空（离场后原位留下凹痕） | 动作卡顿（准备做某事的动作停在半途=情绪裂缝） |

- 三岛式可用「不是A，而是B」作**内心视角自我修正**（观察者校正自己的判断）；叙述层对比说明禁用它。卡佛式则全篇禁。
- 比喻须可触可握，禁抽象填充。眼睛写质地不写颜色；嘴唇写动态（紧抿/微张/咬/干裂/湿润）不写形容词。

### 6. 分章施工手册

每项目建 `plan/施工手册.md`，写作 agent 每章必读：

- **章节结构速查表**：章 / 核心事件 / 亲密场景 / 人格场景 / 钩子。
- **爆点设计（每章三幕）**：冷开场立人设（第一章即展示主角「污点」）→ 核心场景（身体描写+能力/情感暴露）→ 双线钩子（悬念 + 情感重量）。
- **人格场景插位表**：每章可选插入「人格场景」——污点（护食/记仇/想逃）、可爱（对土说话/收藏癖）、正太感（得意忘形/吃软不吃硬）、底色裂缝（门把手停顿/梦话）。用环境与物件讲故事，**禁大段回忆杀**——碎片即可（墙上身高刻度线在 12 岁戛然而止、一副没下完的棋）。
- **章末钩子四选一**：视觉悬念 / 台词悬念 / 能力觉醒 / 威胁逼近。禁「欲知后事如何」式。
- 世界观信息通过场景自然展示，禁堆砌说明段。

### 7. 逐章写作

- **动笔前必读顺序**：`session_context.md`（进度与决策）→ 项目 GOAL（总纲）→ 角色设定 → 施工手册 → 分章大纲 → 技法手册。
- **章节格式规范**：纯 txt，无 markdown 标记；段落连续，行间无空行；场景转场用一行空行；禁连续两个空行。
- **章末格式**（依序，空行分隔）：
  1. `（第X章·完）`
  2. 【章节简介】一句话 ≤50 字（平台章节提要，如适用）
  3. 【作者有话说】≤200 字——本章手记（必选，真实创作感受）+ 细节提示（可选，不解释意义）+ 下章引子（可选，情绪期待非剧透）。语气：网文向可玩梗互动；文学向「像写作者那样聊」，禁「求收藏求订阅」话术。
- **每章通用检查清单**：
  - 视角是否一致（双线作品奇数章 A / 偶数章 B，交汇后混合视角须有切换标记）
  - 台词数量是否超上限
  - 至少 1 处身体部位特写；至少 2 个描写维度
  - 至少 1 处感官描写（气味/温度/触感）
  - 至少 1 处两人距离的空间描写
  - 章末钩子存在（四选一）
  - 世界观信息经场景自然展示
  - 字数达标——用 `bash` 执行 `wc -m`（字符数），非 `wc -c`（字节数），中文字符 UTF-8 下 1 字=3 字节，`wc -c` 虚报三倍
- 写作可委托子 agent（如 `artistry`，温度宜高）执行；链式调用必加 `clarify: false` 与 `timeoutMs`。

### 8. AI 痕迹清除（通用质量要求，防排斥感）

AI 感过强是读者排斥（弃文、拒付费、差评）的首要原因。清除 AI 痕迹属**通用质量要求**，非语言风格本身——风格档案仅决定执行强度（严格/宽松）与破折号额度。下列清单源自 style-imitate 的 AI 痕迹研究，逐项执行：

**8.1 句式禁清单**

| 禁 | 替代 |
|:---|:-----|
| 「不是……而是……」 | 分两句，或直接陈述 |
| 「不仅……而且……」 | 删「不仅」，只说后段 |
| 「值得注意的是/值得强调的是/值得一提的是/需要指出的是/不可否认的是/毫无疑问」 | 直接陈述，不加评注 |
| 「从某种意义上说/在某种程度上/正如前文所述/综上所述/总而言之/这意味着/换言之/不仅如此/更为重要的是/从这个角度来说」 | 直接说内容 |
| 「如下所示/如上所述/如前所述」 | 删掉，或改用「见下表」 |
| 「这一现象/这一问题」泛化指代 | 明确指代对象，或「这」一笔带过 |
| 「首先/其次/最后」作段落开头 | 自然过渡 |
| 「引发了一个重要问题/值得思考的问题」 | 直接呈现事件，不加前戏 |

**8.2 破折号**

- 基准：每 100 字 ≤1 个（对照用户样本）；禁以破折号替代逗号/冒号/括号；禁句末破折号制造「悬念」效果
- 额度随风格档案浮动：严格=零破折号；宽松=每章 ≤25 个（保留重音与插入语）
- 替代方案：解释说明→冒号或逗号；插入语→逗号或括号；强调→调整语序；转折→但/不过/然而

**8.3 段落衔接**

- 禁每段末尾做总结/概括——让段落自然结束
- 禁相同过渡模式连用（「然而→然而→然而」式开篇）
- 禁「帽子句」机械模式（主题句+展开）
- 「但是/然而/不过」作段首：每 2-3 段最多一个

**8.4 措辞**

- 禁堆砌形容词（深刻的、重要的、关键的、显著的）——只用必要的词
- 禁大词替代小词（「实施」替代「做」、「探究」替代「研究」、「是否具备 xx 性」替代「能不能」）
- 禁高频「性/化/度/力」字尾抽象名词（可能性、有效性、系统性、多元化）
- 禁过度「在……中/在……下/在……上」前置状语
- 「体现了/展现了/呈现出」→ 能用「是」就用「是」
- 「这一xxx」→ 直接说「这」或具体主语

**8.5 段落长度**

- 禁连续三个段落长度大致相等——长短自然参差
- 禁段落全部超 5 行——必要时用一两句话的短段

**8.6 句式均匀性（隐蔽 AI 标志）**

清除标记词后，AI 句子结构仍趋于均匀：主谓宾、长度相近、开头模式重复。人类句式分布不均匀。对策：

- 打破段落开头重复：禁连续 3 句以同一主语（他/她）开头，第三句换主语/视角/句式
- 长短句交替；允许自然的碎片化表达
- **勿「过于完美」**：AI 的标志是每句都「对」、每处无懈可击——人类写作有自然节奏变化与偶尔的不规整
- **双峰陷阱（2026）**：长短交替≠机械节拍器——禁「短句、超长句、短句、超长句」循环往复（新模型已学会这种伪突发性，本身就是新指纹）。人类节奏以中等句为主（约 50% 句在 11-25 词 / 30-50 字）、偶向两端摆，不规则变化

**8.7 样本对照原则（防过度修正）**

- 若用户风格样本或已有正文中某表达高频出现，则该表达是用户的「自然风格」而非 AI 痕迹——**保留而非清除**
- 「像用户写的」优先于「符合某个完美标准」——勿过度修正（如用户自身惯用破折号，则破折号额度上调）
- **「人类标记」保留论证**（style-imitate 6.2）：若用户惯用某标记词（如「说实话」「其实」「说到底」），常规清除会把它当 AI 痕迹删除，但保留反而使文本更不像 AI——因为 AI 默认会避免这些表达，用户用了才是人类写作的指纹。判断标准：用户在已发表作品/样本中用过 = 自然风格，保留
- 中文禁西化句式/翻译腔：检查英文语法结构是否被直译成中文

**8.8 终检清单**（每章写毕、精修后各执行一次）

- [ ] 全文无「不是……而是……」及评注语（值得注意的是/综上所述等）
- [ ] 破折号密度符合风格档案额度
- [ ] 无「首先/其次/最后」机械框架、无「帽子句」
- [ ] 无形容词堆砌、「在……中/下/上」滥用、「性/化/度/力」尾词
- [ ] 段落长短参差，无连续等长段、无全篇超长段
- [ ] 无连续 3 句同主语开头
- [ ] 无每段末尾总结句
- [ ] 句式类型混合（叙述/反问/祈使/碎片），未每段完成「主张→证据→涵义」完整弧线
- [ ] 句长分布有起伏，无连续 3 句同长、无机械节拍器式长短交替
- [ ] 读起来不像 AI 写的

**8.9 结构去模板化与叙述灵魂（2026 升级）**

- **四段句 DNA 破除**：AI 文本 82% 遵循「开场→展开→对比→解决」弧线（anti-slop 2026 研究），3-4 句可测、改词无效。每章至少两处打断：段不总以主题句开头；段不总完成「主张→证据→涵义」；允许未解决的张力收尾
- **打破三元组**：不要凡事凑三项（三形容词、三例证、三要点）。按内容需要列 2/4/5 项
- **段落节奏**：一句话段落用于强调；长段落用于持续叙事。禁 2026 新反噬——全篇碎片化小段 + 堆砌
- **叙述灵魂（文学场景专属）**：叙述层允许「有立场的观察者」——对场景有态度、承认复杂感受、允许一点点不规整。但遵循风格档案与 8.7 样本对照原则：用户风格里没有的态度不要硬加
- **事实底线**：改写/精修不丢信息——人物名、时间线、道具状态、已设伏笔不得在去 AI 味过程中丢失（与第 10 节一致性核验衔接）

### 9. 结构审查与精修

- **写作与审查分离**：写作/精修 agent 与结构审查 agent（如 `momus`，温度宜低）分开。审查者**只输出问题列表，禁改任何文字**；修改一律由写作 agent 执行。
- **审查维度**：核心事件与施工手册/大纲一致否；亲密等级匹配否（禁跳级）；人格场景按表插入否；伏笔跟踪表一致否；章末钩子充足否；台词数量超标否；世界观自然展示否；人物一致性档案逐项对照否。
- **精修原则**：只修被指出的问题；保持情节、结构、字数节奏不变；每处插入 ≤2-3 句；不增删段落，只在现有段落中嵌入。
- 审查意见标注严重程度（blocker / warning / info），blocker 必修，warning 视情节定，info 可留。

### 10. 一致性核验与收尾

- **跨章一致性**：固定身体特征（痣/疤/裂痕/道具状态）逐章核对，变化须有叙事理由。
- **关系渐进性**：人物态度变化禁跳跃（从职业化到放松须有中间态）。
- **伏笔更新**：每次写作后更新悬念引爆时间线，标注已埋/已爆。
- 每完成一卷，回读卷首 1-2 章核验伏笔与基调。

## 注意事项

- **风格禁自行确认**：用户未给风格指示时，必先 `ask_user` 再动笔，禁代用户选定。
- **风格参数是选择，非铁律**：两项目为例——破折号：A 项目每章 ≤25 个（保留重音与插入语），B 项目零破折号（AI 痕迹最显著标志）；「不是……而是……」：叙述层皆禁，内心视角自我修正可例外；AI 痕迹规则：B 项目严格（全篇禁「仿佛/某种/那一刻/突然/却/竟/便/是……的」等），A 项目宽松。新项目取哪档，由用户定。
- **AI 痕迹清除是质量底线，非风格选择**：步骤 8 全清单适用于所有项目，仅执行强度与破折号额度随风格档案浮动；用户样本中高频出现的表达保留，禁过度修正（样本对照原则 8.7）。
- **亲密禁跳级**：感情线须按五级递进，不可从视线占有直接跳到公开确认。
- **强强底线**：受可被控制，不可被摧毁精神；攻可冷，不可真的无情。
- **平台红线**：禁非自愿/强迫性关系描写；禁道德说教；禁美化苦难（若用户选现实主义风格）。
- **伏笔必录跟踪表**：遗漏引爆节点是长篇小说最常见事故。
- **本 skill 不涉推广运营**：发布策略、评论区运营、收入分析、Tag 优化等不在范围内；【作者有话说】仅作创作温度，不作营销工具。
- 写作 agent 切换前必读 `session_context.md`，防重复决策。
- 已存在项目沿用其风格档案与施工手册，勿按本 skill 重建（本 skill 仅作查缺补漏参考）。
