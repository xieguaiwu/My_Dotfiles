# 难度升级框架 (Difficulty Escalation Framework)

本文件是所有出卷/出题 skill（`exam-paper-cloner`、`ap_csa_generation`、`mistake-practice-generation` 等）的**共享难度设计规范**。出题时遇到"如何让题目更难"的问题，一律按本框架执行，禁止凭直觉堆料。

## 1. 核心哲学

> **难度 = 认知负荷的类型与深度，不是任务量。**

| 错误认知 ❌ | 正确认知 ✅ |
|------------|------------|
| 更难 = 计算量更大 / 式子更长 | 更难 = 思维方向反转、抽象层次提升、概念边界辨析 |
| 更难 = 句子更长 / 生僻词更多 | 更难 = 结构层次更深、推理层级更高、语义甄别更细 |
| 更难 = 更多步骤的同类机械操作 | 更难 = 每步简单但链条组织需要策略 |
| 更难 = 更多背景知识要求 | 更难 = 用已有知识处理陌生情境（迁移） |

**判据**：一道难题做完，学生应能说出"我学到了什么思考方式"，而不是"我算了好久"。前者是可迁移的能力，后者是浪费时间。

## 2. 学科分轨

出题前**必须先分类**，再选择升级维度：

| 轨 | 学科 | 允许的升级方式 | 严禁 |
|----|------|--------------|------|
| **数理轨** | 数学、物理、化学、统计、CS/编程 | D1-D12 维度（§3） | **堆砌计算量**：长多项式展开、超大数运算、连环代入、更多层嵌套循环、超长代码追踪、巨型配平、多步摩尔连环计算 |
| **文科轨** | 语言、阅读、写作、历史、SAT R&W | L1-L10 维度（§4），含句法复杂度 | 生僻词堆砌、故意晦涩（obscurantism）、超纲背景知识、信息重复的长句 |
| **混合轨** | 数学文字题、SAT 数学、AP 经济/生物 | 两轨维度按需组合（每题 ≤ 2 个） | 两轨禁止项均生效 |

**混合轨合法组合示例**（每题 ≤ 2 个维度，D+L 各取所需，必须有明确的教学理由）：
- SAT 数学文字题：D6（多步推理链——题干信息需逐层提取中间量）+ L3（推理层级——先判断题目在问哪一层）
- AP 经济图表题：D12（信息充分性——数据是否足以支撑结论）+ L7（证据权衡——哪组数据支撑哪条结论）
- AP 生物实验设计题：D3（边界情况——对照组/变量极端取值）+ L9（逻辑论证——实验结论依赖的假设前提）

## 3. 数理轨维度矩阵（D1-D12）

每个维度：操作 → 示例（Easy → 升级后）→ 与堆料的区别。

| # | 维度 | 操作 | 示例（Easy → 升级） | 与堆料的区别 |
|---|------|------|---------------------|--------------|
| **D1** | 概念辨别 Concept Discrimination | 区分易混概念/定义的适用边界 | 算 `∫x²dx` → 判断"f 在 [a,b] 连续 ⇒ F(x)=∫ₐˣf 可导且 F'=f 处处成立？"（微积分基本定理适用条件） | 计算量几乎为零，考定义边界 |
| **D2** | 逆向推理 Reverse Reasoning | 给结果求条件/反推参数 | 已知 f(x)=x²−4x+3 求切线 → 已知过点 (1,0) 的直线与曲线相切，求切点个数 | 思维方向反转，正向计算反而帮不上忙 |
| **D3** | 边界情况 Edge Cases | 追问参数/条件的极端取值 | 解 2x=4 → 解 ax=b（讨论 a=0 无解/无数解） | 考对假设的敏感性，不是算得多 |
| **D4** | 参数化与一般化 Parameterization | 具体数值 → 一般公式/证明通式 | 求 5 个数的中位数 → 证明任意 n 个数中至多 ⌈n/2⌉ 个严格小于中位数 | 抽象层次提升，具体数字消失 |
| **D5** | 概念迁移 Transfer | 熟悉概念应用到陌生情境 | 求位移（速度积分）→ 经济学边际成本 = 成本函数导数，解释为什么 | 跨域连接，考察概念本质而非操作 |
| **D6** | 多步推理链 Multi-step Chain | 3-5 步逻辑链，中间量不直接给出 | 直接积分 → 数列 aₙ₊₁=f(aₙ)：证明单调有界 → 收敛 → 求不动点极限 | 每步心算可完成，难在链条组织与中间量定义 |
| **D7** | 反例构造 Counterexample | 判断命题真假并证伪 | "可导 ⇒ 连续"（真）→ "连续 ⇒ 可导"（假，构造 \|x\|） | 考逻辑与构造力，零计算 |
| **D8** | 错误诊断 Error Diagnosis | 给出含典型错误的解法，找错+解释+修正 | 自己算 → 学生解法中哪一步错了？为什么错？正确做法？ | 元认知维度，直接对应"看懂他人错误" |
| **D9** | 约束优化 Constrained Optimization | 多约束下求最优/权衡；含**多解法比较**（两个都正确的方法哪个更优？为什么） | 求极值 → 周长固定面积最大（多约束）或"哪个方案更优？为什么"（trade-off） | 策略选择优先于机械计算 |
| **D10** | 估算与合理性 Estimation | 数量级判断、量纲分析、结果合理性检验 | 精确计算 → 不计算，判断数量级；或"学生算出概率 0.014，据题设（万人中发病率约 1/1000）这个量级合理吗？为什么" | 直觉校准，反堆料的天然武器 |
| **D11** | 证明与论证 Proof & Rigor | 解释"为何成立"，论证充分性/必要性 | 用洛必达法则 → 说明为什么 0/0 与 ∞/∞ 之外的情形不能直接用 | 论证完整性，不是套公式 |
| **D12** | 信息充分性 Information Sufficiency | 条件多余/缺失的判断 | 所有条件给全 → "以下哪个附加条件足以保证结论？哪个条件多余？" | 信息处理能力，不增加计算 |

### 3.1 数理轨升级操作规则

1. **每道题只升级一个维度**（保证诊断性：学生错在哪一维一目了然）
2. Hard 题最多组合 2 个维度（如 D6+D3），且其中至少一个为深度应用
3. **干扰项 = 错误概念/常见误解，不是计算错误**：Hard 题的正确选项与干扰项在数值上不应因"算错"而区分，而应因"概念理解"而区分
4. 同卷内 Easy→Hard 沿同一维度加深，或每次只加一个新维度（递进链）
5. 升级必须对应明确能力目标（理解/分析/评价/创造，Bloom 层次），无目标不升级

## 4. 文科轨维度矩阵（L1-L10）

| # | 维度 | 操作 | 示例（Easy → 升级） | 与堆料的区别 |
|---|------|------|---------------------|--------------|
| **L1** | 句法复杂度 Syntactic Complexity | 嵌套从句、插入语、长距离依赖（修饰语与中心词距离拉远）、多重否定、隐蔽平行结构 | 短句 → "The report, drafted by economists who had spent three years studying the policy's effects on rural communities, criticized the policy in terms that surprised even its authors."（Medium 示例：非限定性关系从句 + that 补语从句） | 长度增加必须伴随**结构层次**增加；信息不重复、形容词不堆砌 |

**L1 有效性操作测试**（防"看起来长"的假复杂度）：
1. 句中必须出现至少一种结构标记：非限定性关系从句（删去会改变指代/语义）、修饰语与中心词相隔 ≥8 词的长距离依赖、多重否定（极性需解析）、嵌入 ≥2 层从句
2. **拆分测试**：若该句能拆成两个短句且信息零损失 → 判定为堆料，重写
3. 删除任一从句后若句子语义完整且无指代歧义变化 → 该从句只是装饰，不算复杂度
| **L2** | 语义精度 Semantic Precision | 近义词在 connotation/register/collocation 上甄别 | "said" → 在 refuted/rejected/denied/dismissed 中选"最精确"的（四个语法都对） | 需要语境证据，考语感 |
| **L3** | 推理层级 Inference Level | Bloom 提升：定位 → 理解 → 推断 → 分析 → 评价 | "文中提到…" → "暗示…" → "作者论证最弱的一环是…" | 思维深度递增，文本长度不变 |
| **L4** | 结构意识 Structural Awareness | 段落功能（承上启下/让步/反驳）、整体组织、句子在论证中的角色 | "这段话讲了什么" → "这段话在全文论证中的作用？删去第三段论证损失什么？" | 宏观视角，非局部信息 |
| **L5** | 多文本关联 Cross-text | 双篇作者互答、观点映射、差异比较 | 单篇理解 → "Text 2 作者会如何回应 Text 1 的主张？哪个具体观点与之冲突？" | 综合能力 |
| **L6** | 修辞细腻 Subtle Rhetoric | 反讽、轻描淡写、言不由衷、tone shift、故意歧义 | 识别明示情感 → 判断作者对人物是同情还是嘲讽（证据 = 选词："charming" vs "self-important"） | 微观语感，考"没说出来但写出来"的部分 |
| **L7** | 证据权衡 Evidence Evaluation | 冲突证据中选择支持结论的最佳证据；数据与结论匹配（区分相关/因果、趋势/例外） | 找支持句 → 表格数据哪个选项准确描述了数据与结论的关系 | 批判性思维，考数据解读 |
| **L8** | 隐含信息 Implicature | 言外之意、预设、会话含义 | "A: 报告写完了吗？B: 初稿写完了。" → 可推出什么？**不可**推出什么？ | 推断边界的精确控制 |
| **L9** | 逻辑论证 Logical Argument | 识别谬误（滑坡/稻草人/错误二分）、前提→结论结构、支持/削弱 | "这个论证对吗" → "找出论证中最薄弱的假设并说明如何削弱" | 逻辑素养，非知识量 |
| **L10** | 语境词汇 Words in Context | 生词/多义词在具体语境的精确含义，排除表面义 | 词典义 → "bland" 修饰 report 与 food 的语义差异 | 猜词策略与语境证据 |

### 4.1 文科轨升级操作规则

1. **句法复杂度（L1）是合法且推荐的升级工具**——但"长"必须伴随"结构层次"：嵌套、插入、长距离依赖、多重否定。信息重复的加长是堆料，禁止
2. **Hard 题所有选项必须自身语法正确**，仅语义/逻辑区分；至少 2 个选项"表面正确"（学生读完第一遍觉得都对）
3. 推理层级（L3）是性价比最高的升级：文本不变，提问变深
4. 禁止用生僻词/超纲背景知识制造难度（那不是考能力，是考运气）

## 5. 递进阶梯（Easy → Medium → Hard 标准路径）

### 数理轨

| 难度 | 结构 | 维度用法 |
|------|------|---------|
| Easy | 单概念直接应用，数值直接给出 | 1 个维度基础版（如 D1 表面区分） |
| Medium | 两概念组合，一步逆向 | 1 个维度加深 或 2 个浅层组合 |
| Hard | 多步推理链 + 边界/迁移 | 2 个维度（≤2），至少一个深度版；干扰项对应概念错误 |

> **浅层 vs 深度应用定义**（供 Medium/Hard 判定）：浅层 = 维度特征明显、一眼可识别（如 D1 区分两个明显不同的概念；L3 单步推断）；深度 = 维度特征隐蔽、需细读才能定位（如 D1 三个近义概念在给定条件下仅一个成立；D6 链条中至少一步需自定义中间量；L3 需跨段落综合才能推断）。"1 个维度加深" = 同一维度的浅层→深度；"2 个浅层组合" = 两个维度均浅层呈现且相互独立。

### 文科轨

| 难度 | 结构 | 维度用法 |
|------|------|---------|
| Easy | 单句理解、直接定位 | 基础句法 + 直接信息 |
| Medium | 长句分析、单步推断 | L1 加深 或 L3 单步推断 |
| Hard | 多文本综合 + 修辞细腻 + 评价判断 | L1+L3 / L3+L5 / L6+L7 等组合（≤2 个） |

## 6. 反堆料检查清单（每卷强制自检）

生成完成后逐条核对，任何一条不满足 → 重设计该题，不妥协：

- [ ] **计算量红线（数理轨）**：Hard 题计算量 ≤ 同卷 Easy 题的 3 倍？超过 → 砍计算、换维度（D1/D2/D7/D11 优先）
- [ ] **机械步骤**：难题不是"更多步骤的同类机械运算"？（连环代入、更多层循环 = 堆料）
- [ ] **信息密度（文科轨）**：长句信息不重复？长度来自结构层次而非形容词/修饰语堆砌？
- [ ] **单维升级**：每题只升级一个维度？Hard 题维度数 ≤ 2？
- [ ] **能力目标**：每个升级对应明确能力（理解/分析/评价/创造）？无目标不升级
- [ ] **可验证性**：Hard 题答案可证明/可验证？不可验证的硬题必须删除或改题（防"答案对但无法确认"）
- [ ] **策略收益**：学生做完能提炼可迁移策略？纯堆料题无策略收益 → 重设计

> **基线锚定**：3 倍判据的基准是"同卷 Easy 题的认知复杂度"。Easy 题不得为迁就判据而人为膨胀（Easy 必须保持直观），否则判据整体失效。判定机械步骤时问："去掉这题的后 80% 步骤，能力考察是否不变？"是 → 堆料。

## 7. 难度档案（Difficulty Profile）标注规范

每份试卷/练习卷必须携带难度档案，标注在源文件头部注释与交付报告中：

```
% Difficulty Profile
%   Distribution: standard 档 Easy 30% / Medium 50% / Hard 20%
%   STEM dimensions: D1, D2, D6, D7        (数理轨)
%   Liberal-arts dimensions: L1, L3, L5    (文科轨)
%   Escalation rule: one dimension per question; Hard ≤ 2 dimensions
```

**分布比例唯一权威来源**：三档 canonical 分布由各 skill 的 `difficulty` 参数统一定义——`standard` = 30/50/20、`hard` = 15/40/45、`max` = 0/30/70（见 exam-paper-cloner §6.3）。任何 skill 不得另立第四套分布；确有特殊需求（如错题诊断卷）须显式说明理由并标注偏离。

每题在源码注释行标注：`% diff: hard | D6+D3`（难度 + 维度）。答案文件的解析末尾标注该题考察的维度与能力目标（如 `Dimension: D6 multi-step chain; Goal: analysis`）。

## 8. 系列卷难度递增计划

多套练习卷（set1 → set2 → set3）按维度渐进展开，每套卷记录难度档案：

| 系列 | 侧重 | 说明 |
|------|------|------|
| set1 | 单维度基础 | 每家族只考 1 个维度（D1/D2 或 L1/L2），帮助学生建立维度意识 |
| set2 | 单维加深 + 双维组合 | 同维度深度版 + 少量 2 维组合题 |
| set3 | 双维深度 + 迁移 | 双维深度应用（其中至少一维以跨章节/跨学科迁移方式呈现；**仍 ≤ 2 维**） |

系列 README 记录每套难度档案与维度覆盖表，确保维度不重复堆叠在同一技能上。

## 9. 干扰项配套规则（随难度升级）

| 难度 | 数理轨干扰项 | 文科轨干扰项 |
|------|-------------|-------------|
| Easy | 常见计算错误 + 1 个概念混淆 | 1 个明显语法错误 + 1 个近义混淆 |
| Medium | 概念混淆为主，计算错误为辅 | 全部语法正确，1-2 个语义混淆 |
| Hard | **全部对应概念错误/误解**（禁计算错误充数） | 全部语法正确且"表面成立"，仅靠语义/逻辑精微区分 |

## 11. 答案与解析要求（难度升级后强制）

1. **Hard 题解析必须含完整推理链**：为什么对（逐步）+ 为什么每个干扰项错（对应其概念误解），不是只给结论
2. 解析标注维度与能力目标（见 §7）
3. 数理轨 Hard 题解析附"可能的失败点"：学生在哪一步会卡住/走错，及如何自查
4. 文科轨 Hard 题解析必须给出"排除每个选项所需的证据"（选项 → 文本证据 → 判断），防止学生凭感觉选
5. 解析语言：数理轨用 LaTeX 推导；文科轨用引文证据支撑
